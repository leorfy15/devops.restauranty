Flagship project

Restauranty — Azure AKS DevOps Platform

Containerized microservices platform, deployed and operated on Azure Kubernetes Service, with an AI assistant wired into live cluster and security data.

View repo →
  • Containerized and deployed a multi-service app (React frontend, 3 Node/Express services, MongoDB) to Azure Kubernetes Service, with images stored in Azure Container Registry.
  • Built CI/CD foundations with GitHub Actions and Azure OIDC authentication, plus Kubernetes Ingress, DNS and TLS/HTTPS for externally accessible services.
  • Stood up observability with Prometheus, Grafana and Loki/Grafana Alloy for infrastructure, application and security monitoring.
  • Deployed a Cowrie SSH/Telnet honeypot in an isolated namespace and exposed recent attack activity through an AI-assisted operations interface.
  • Ran container vulnerability scanning with Trivy — surfaced real HIGH/CRITICAL findings in application images.
  • Troubleshot Kubernetes, networking, authentication, MongoDB and resource-management issues end-to-end with kubectl and logs.

"Instead of manually going through logs, the goal was to ask ‘are my pods healthy?’ or ‘what commands did the attacker execute?’ — the assistant routes the request to an approved operation and returns a human-readable answer, never raw shell or database access."
